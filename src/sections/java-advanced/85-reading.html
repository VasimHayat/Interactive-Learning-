Where to go next

Further reading

Primary sources only — the specification chapters that define the memory model and class loading, the JEPs behind each runtime feature, the HotSpot documentation, and the few books worth the shelf space. These are links, but nothing on this page loads them; the module remains fully offline.

Specifications

  • JLS SE 21, Chapter 17 — Threads and Locks — the Java memory model itself: happens-before, the definition of a data race, the rules for volatile and final fields, and wait/notify semantics. Dense, but §17.4 is the one chapter every concurrency claim in this module traces back to (§1, §2, §3).
    https://docs.oracle.com/javase/specs/jls/se21/html/jls-17.html
  • JLS SE 21, §12.4 — Initialization of Classes and Interfaces — the exact list of what triggers initialization and the locking procedure that makes it happen once (§10).
    https://docs.oracle.com/javase/specs/jls/se21/html/jls-12.html#jls-12.4
  • JVMS SE 21, Chapter 5 — Loading, Linking, and Initializing — loading, verification, preparation, resolution, and the class-loader delegation contract, from the virtual machine's side (§10).
    https://docs.oracle.com/javase/specs/jvms/se21/html/jvms-5.html
  • Java Object Serialization Specification — the stream format, writeReplace/readResolve, and the record serialization rules (§14).
    https://docs.oracle.com/en/java/javase/21/docs/specs/serialization/index.html

The JEPs

  • JEP 444: Virtual Threads — the design, the mounting model, what pins, and why pooling them is wrong (§7).
    https://openjdk.org/jeps/444
  • JEP 453: Structured Concurrency (Preview) — StructuredTaskScope and the argument for treating a group of subtasks as one unit (§7).
    https://openjdk.org/jeps/453
  • JEP 491: Synchronize Virtual Threads without Pinning — the Java 24 change that removes the synchronized pinning described in §7.
    https://openjdk.org/jeps/491
  • JEP 439: Generational ZGC — why a concurrent collector still wants generations, and the -XX:+ZGenerational flag (§8).
    https://openjdk.org/jeps/439
  • JEP 290: Filter Incoming Serialization Data and JEP 415: Context-Specific Deserialization Filters — ObjectInputFilter, jdk.serialFilter, and the filter factory (§14).
    https://openjdk.org/jeps/290 · https://openjdk.org/jeps/415
  • JEP 261: Module System — the module path, readability, the unnamed and automatic modules, and the --add-* flags (§12).
    https://openjdk.org/jeps/261
  • JEP 403: Strongly Encapsulate JDK Internals — the Java 17 change behind every InaccessibleObjectException (§11, §12).
    https://openjdk.org/jeps/403
  • JEP 328: Flight Recorder — what JFR records and why its overhead is low enough for production (§13).
    https://openjdk.org/jeps/328

HotSpot documentation

  • HotSpot Virtual Machine Garbage Collection Tuning Guide — the generations, each collector's knobs, and the ergonomics that pick defaults for you (§8, §9).
    https://docs.oracle.com/en/java/javase/21/gctuning/index.html
  • JDK Mission Control and jfr tool documentation — recording, the event catalogue, and reading a recording from the command line (§13).
    https://docs.oracle.com/en/java/javase/21/jfapi/ · https://docs.oracle.com/en/java/javase/21/docs/specs/man/jfr.html
  • java.util.concurrent package summary — the "Memory Consistency Properties" section states, in one page, every happens-before edge the library provides (§2, §4, §5).
    https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/util/concurrent/package-summary.html
  • JMH — Java Microbenchmark Harness — the samples directory is the documentation; read them in order, they are numbered (§13).
    https://github.com/openjdk/jmh

Books

  • Java Concurrency in Practice, Brian Goetz et al. — still the reference for §1 to §6. It predates virtual threads and CompletableFuture, but the model it teaches — publication, confinement, invariants, the memory model — is exactly what those features are built on. Read it cover to cover.
  • Optimizing Java, Benjamin J. Evans, James Gough and Chris Newland — GC internals, the JIT, JMH, JFR and the measurement discipline of §8, §9 and §13, written for working engineers rather than JVM implementers.
  • The Java Module System, Nicolai Parlog — the long-form treatment of §12, including the migration strategy for a class-path application.
  • Inside the Java Virtual Machine, Bill Venners — dated in detail (it predates HotSpot's JIT) but the clearest conceptual account of class loading, linking and the execution model in §10.
  • Effective Java, Joshua Bloch, 3rd edition — items 78 to 84 are the concurrency chapter; items 85 to 90 are the case against serialization that §14 summarises.

Where to go from here

This is the last module of the course. Everything from here is practice on real systems, and three things will teach you more than any further reading.

  • Finish the lab's extensions. Each one — a reservation timeout, a rate limiter on the quote service, an idempotent transfer log — forces a design decision this module only described.
  • Read Java Concurrency in Practice cover to cover, now that every chapter has a section here you can check it against. Then reread §2: the memory model is the part people get wrong years into their careers.
  • Profile a real service. Attach JFR to something you run, for an hour, under real load. Read the GC log, take a thread dump during a slow request, find the three hottest methods. Nothing in §8, §9 or §13 is really yours until you have done that once on a system whose behaviour you did not already know.
