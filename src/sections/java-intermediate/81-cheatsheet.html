Wildcards go in parameters, never return types. Erasure forbids new T(), new T[n], instanceof List<String>, List<int>, static T, catch (T e), and two overloads that differ only by type argument.

Records §8

  • Header = complete state. Generated: private final fields, canonical constructor, name() accessors, equals, hashCode, toString.
  • Compact constructor Line { sku = sku.strip(); if (qty <= 0) throw …; }: validate and normalise the parameters; fields are assigned after the body. Other constructors must delegate with this(…).
  • Implicitly final; no extends; may implements; no instance fields beyond components; nested records are static; local records cannot capture locals.
  • Immutability is shallow: copy collection components with List.copyOf in the compact constructor; arrays break equals — use a List.
  • Not a record: anything with identity, anything that mutates, anything that needs a superclass or a no-arg constructor.

Sealed types and pattern switch §9

sealed interface Discount permits PercentOff, FixedOff, BuyNGetOne {}
record PercentOff(int pct) implements Discount {}
record FixedOff(int cents) implements Discount {}
record BuyNGetOne(int n) implements Discount {}

long apply(Discount d, long gross, int qty) {
    return switch (d) {                                         // expression: must be exhaustive
        case null                       -> gross;               // without this, null throws NPE
        case FixedOff(int c) when c >= gross -> 0;              // guarded case first…
        case FixedOff(int c)            -> gross - c;           // …then the unguarded one
        case PercentOff(int pct)        -> gross * (100 - pct) / 100;
        case BuyNGetOne(int n)          -> { long free = qty / (n + 1); yield gross - free * (gross / qty); }
    };                                                          // no default: a new subtype is a compile error
}
Pattern forms
PatternExampleRule
Typecase String s ->specific before general, or "dominated by a preceding case label"
Recordcase FixedOff(int c) ->binds components by position; accessors run during matching
Nested recordcase Line(Product(var sku, var p), int qty) ->var infers each component
Guardcase FixedOff(int c) when c >= gross ->a guard is not a case: an unguarded one is still required
Nullcase null -> / case null, default ->otherwise a null selector throws
instanceofif (o instanceof String s && s.length() > 3)binding is in scope wherever the test must have passed

Permitted subtypes must be final, sealed or non-sealed, in the same package or module. Exhaustiveness is checkable only for enums and sealed types. Sealed switch when types are fixed and operations grow; polymorphism when operations are fixed and types grow.

java.time types and when to use them

InstantUTCwhen something happened — store and log this

Everything is immutable: use the return value. ZoneId.of("Europe/London"), never "BST". Pattern formatters need a Locale; yyyy not YYYY (week-based year), MM month, mm minute, HH 0–23. Month arithmetic clamps (31 Jan + 1 month = 28 Feb). Inject a Clock to test. ZonedDateTime.equals compares zone and fields; use isEqual for the instant.
