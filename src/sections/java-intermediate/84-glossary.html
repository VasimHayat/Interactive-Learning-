Glossary

Thirty terms, each linked back to the section that introduces it. The same entries drive the flashcard deck below — one list, two ways to use it.

Flashcards

Bounded type parameter
<T extends Product>: a type variable that may only be instantiated with a subtype of the bound, which is what lets the method call Product's methods on a T. An intersection bound T extends Product & Stockable requires both. §1
Charset
The mapping between bytes and characters. A file does not record which one it was written with, so reading with the wrong charset throws MalformedInputException or produces Ã© for é. Always pass StandardCharsets.UTF_8 explicitly. §13
Collector
The recipe collect uses to accumulate a stream into a result: how to create a container, add an element, merge two containers and finish. Collectors supplies every common one — toList, toMap, groupingBy, joining, counting. §6
Compact constructor
A record constructor written without a parameter list — Line { sku = sku.strip(); } — whose body runs before the compiler's automatic field assignment. The place to validate and normalise; assigning this.x inside it is a compile error. §8
Comparator
An ordering supplied from outside the class, built with comparing, thenComparing, reversed and nullsFirst. Should return 0 only for elements that are equals, because TreeSet uses nothing else to detect duplicates. §10
Default method
An interface method with a body that implementers inherit unless they override it. Resolved by three rules: a class wins over an interface, a more specific interface wins over a less specific one, otherwise the class must override. Cannot override an Object method. §3
Defensive copy
Copying a mutable argument on the way into a class (new ArrayList<>(list), List.copyOf) and copying or wrapping on the way out, so no caller can reach the internal state. Rule two of an immutable class. §10
Downstream collector
The second collector handed to groupingBy or partitioningBy, applied to the elements inside each bucket: groupingBy(Product::category, summingLong(Product::value)). mapping, filtering and collectingAndThen adapt it. §6
DST gap
The hour that does not exist when clocks go forward — 01:00–01:59 in London on 29 March 2026. A ZonedDateTime placed in it is shifted forward by the gap's length; a day crossing it has 23 hours. The overlap in October is the hour that happens twice. §12
Duration versus Period
A Duration is elapsed seconds — a stopwatch — and moves the instant. A Period is calendar fields (years, months, days) and moves the wall clock. plusHours(24) and plusDays(1) differ by an hour across a DST change. §12
Effectively final
A local variable that is assigned exactly once and never changed, whether or not it is declared final. Only such locals may be captured by a lambda or inner class, because capture copies the value and a later write would leave two copies that disagree. §2
Erasure
The compiler checks generic type arguments and then drops them: bytecode holds a plain List and a checkcast at every read. Why new T(), new T[n], instanceof List<String>, List<int> and overloads differing only by type argument are all impossible. §1
Exhaustiveness
The compiler's proof that a switch expression handles every possible value of its selector. Checkable only for enums and sealed types, where the complete set is known; a default satisfies it but hides any subtype added later. §9
Fail-fast iterator
An iterator that remembers the collection's modCount at creation and throws ConcurrentModificationException on the next next() after any structural change it did not make. No threads needed. Remove safely with Iterator.remove or removeIf. §11
Functional interface
An interface with exactly one abstract method (defaults and statics do not count), which is what a lambda or method reference implements. Function, Predicate, Supplier, Consumer, Comparator, Runnable. @FunctionalInterface makes the compiler enforce it. §4
Guard
A when clause on a switch case — case FixedOff(int c) when c >= gross — that restricts the pattern to values satisfying a condition. A guarded case covers only some values of its type, so an unguarded case for that type is still required. §9
Inner class
A nested class declared without static. Every instance holds a hidden this$0 reference to the enclosing instance, so it can only be created through one (order.new Cursor()) and keeps the outer object alive. If it does not use the outer instance, make it static. §2
Instant
A point on the timeline, measured in nanoseconds from 1970-01-01T00:00Z, with no zone and no ambiguity. The type to store and log for anything that has happened; convert to a ZonedDateTime only to display. §12
Lazy evaluation
Nothing in a stream pipeline runs until a terminal operation pulls, and then elements flow one at a time through every stage. Buys short-circuiting and the ability to process sources larger than memory; a pipeline with no terminal is a silent no-op. §5
Load factor
The fill ratio at which a HashMap doubles its table and rehashes every entry: 0.75 by default, so a 16-bin map resizes on its 13th entry. Iteration order changes at each resize; a bin reaching 8 entries in a table of 64 or more becomes a tree. §11
Method reference
Shorthand for a lambda whose body is one call forwarding its parameters: static (Integer::parseInt), bound (sample::sku — receiver fixed when created), unbound (Product::sku — receiver is the first parameter), constructor (Product::new). §4
Optional
A container holding one value or nothing, used as a return type to say "may be absent". Consume it with map, flatMap, filter, then orElse, orElseGet or orElseThrow. Never a field, a parameter or a collection element; never get(). §7
PECS
Producer Extends, Consumer Super. A parameter the method only reads from is List<? extends T>; one it only writes to is List<? super T>; one it does both with has no wildcard. The signature of Collections.copy. §1
Record pattern
case PercentOff(int pct) ->: a switch or instanceof pattern that tests the type and deconstructs the record's components into variables in one step. Nests — Line(Product(var sku, var p), int qty) — and runs the accessors to bind. §9
Sealed type
A class or interface whose complete set of direct subtypes is declared with permits, each of which must be final, sealed or non-sealed. Gives the compiler the closed set it needs to check a pattern switch for exhaustiveness. §9
Short-circuiting operation
A stream operation that can finish without seeing every element: limit and takeWhile among the intermediates, findFirst, anyMatch, allMatch and noneMatch among the terminals. Only laziness makes them possible. §5
Stateful operation
A stream operation that must remember earlier elements: sorted buffers everything before emitting its first element, distinct keeps a set of what it has seen. Barriers to laziness that need memory proportional to the input; put filter before them. §5
Target typing
A lambda has no type of its own; the compiler takes its parameter types and the interface it implements from the context it appears in — an assignment, a method parameter, a return. The same (a, b) -> a + b is a BinaryOperator<Integer> or a BiFunction<String,String,String>; with var it is an error. §4
Unmodifiable view
Collections.unmodifiableList(src): a wrapper that refuses writes through itself but shows whatever the underlying list currently holds. Not immutable — the source can still change. List.copyOf is the snapshot that cannot. §10
Wildcard
? in a type argument, standing for an unknown type: ? extends T (some subtype), ? super T (some supertype), or unbounded. Loosens invariance for a parameter in one direction, at the price of restrictions inside the method. Belongs in parameters, not return types. §1
