How to use this module

Work through it at your own pace. Your section checkmarks, quiz answers, flashcard marks and notes are saved in this browser under a key scoped to this file, so closing the tab loses nothing and Java Fundamentals cannot overwrite it. Nothing is sent anywhere — this page makes no network requests at all. Press ? at any time for the keyboard shortcuts, and use Reset progress in the sidebar to start over.

Every code sample in this module was compiled and executed against a real JDK 21 as part of the build. If an Expected output block appears under a program, that text is what the program actually printed, not what it ought to print. Where a widget animates execution rather than reporting it — the step-through of how a stream pulls elements, or how javac erases a type argument — it is labelled Simulated. Java cannot run in a browser, and this module does not pretend otherwise.

The same warehouse, grown up

Fundamentals built a small inventory system: a Product with a SKU and a price, an Order of OrderLines, and an InventoryService. This module keeps every one of those types and rewrites them with the tools it teaches:

  • Product gains a Category enum with per-constant behaviour (§3), and the catalogue is queried with streams (§5).
  • Order and OrderLine become records (§8), validated in compact constructors and used as map keys without a hand-written equals.
  • A sealed Discount family — percentage, fixed amount, buy-N-get-one — is priced with an exhaustive pattern switch (§9).
  • A reporting pipeline groups revenue by category with collectors (§6), ranks products with comparators (§10), filters by date with java.time (§12) and writes the result with java.nio.file (§13).
