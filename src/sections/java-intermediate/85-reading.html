Further reading

Primary sources only — the specification chapters and JEPs that define each feature, the package summaries that document the library, and the books that are actually worth the shelf space. These are links, but nothing on this page loads them; the module remains fully offline.

The Java Language Specification, SE 21

The final word on every rule in this module. Each chapter below is short enough to read in one sitting.

  • §4.10 Subtyping and §4.5.1 Type arguments — invariance, wildcards and the capture conversion behind every CAP#1 error message (§1).
    https://docs.oracle.com/javase/specs/jls/se21/html/jls-4.html
  • Chapter 5 Conversions and Contexts — the assignment, invocation and casting contexts that drive target typing and inference (§1, §4).
    https://docs.oracle.com/javase/specs/jls/se21/html/jls-5.html
  • §8.1.1.2 sealed and non-sealed classes, §8.4.3 default methods and §8.10 Record classes — the exact rules for permitted subtypes, default-method resolution and compact constructors (§3, §8, §9).
    https://docs.oracle.com/javase/specs/jls/se21/html/jls-8.html
  • §14.11 The switch statement, §14.30 Patterns and §15.28 Switch expressions — exhaustiveness, dominance and the scope of pattern variables (§9).
    https://docs.oracle.com/javase/specs/jls/se21/html/jls-14.html
  • §15.27 Lambda expressions and §15.13 Method reference expressions — what a lambda may capture, what this means inside one, and how the four reference forms are compiled (§2, §4).
    https://docs.oracle.com/javase/specs/jls/se21/html/jls-15.html

The JEPs

Each feature's design document explains the alternatives that were rejected, which is often the clearest way to understand why the rules are what they are.

  • JEP 395: Records — why accessors are name(), why there are no setters, and the "transparent carrier" phrase (§8).
    https://openjdk.org/jeps/395
  • JEP 409: Sealed Classes — the permits rules and the expression-problem motivation (§9).
    https://openjdk.org/jeps/409
  • JEP 441: Pattern Matching for switch and JEP 440: Record Patterns — guards, case null, dominance and nested deconstruction (§9).
    https://openjdk.org/jeps/441 · https://openjdk.org/jeps/440
  • JEP 400: UTF-8 by Default — why the platform charset was a bug for twenty-five years and what changed in Java 18 (§13).
    https://openjdk.org/jeps/400

Package documentation

  • java.util.stream package summary — the authoritative description of laziness, stateless versus stateful operations, non-interference and the rules for reduce and collect. Read it in full once (§5, §6).
    https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/util/stream/package-summary.html
  • java.time package summary — the type matrix, the ISO calendar, and the design rationale for separating instants from local date-times (§12).
    https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/time/package-summary.html
  • HashMap class documentation — the load-factor trade-off and the treeification note, in the JDK's own words (§11).
    https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/util/HashMap.html
  • Optional class documentation — the API note stating that it is intended as a return type (§7).
    https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/util/Optional.html

Books

  • Effective Java, Joshua Bloch, 3rd edition — items 26 to 33 are the generics chapter (raw types, wildcards, PECS, heterogeneous containers); items 42 to 48 cover lambdas, method references and streams; item 55 is the definitive statement on Optional. Every section of this module has an item behind it.
  • Modern Java in Action, Raoul-Gabriel Urma, Mario Fusco and Alan Mycroft — the long-form treatment of streams, collectors and functional style, with the parallel-stream internals this module deferred to Java Advanced.
  • Java Generics and Collections, Maurice Naftalin and Philip Wadler — older, but still the clearest book-length explanation of wildcards, erasure and the collections framework's design.

Tools worth knowing now

Useful JDK tools for this module's material
ToolUse it to
jshellBuild a stream pipeline one operation at a time and watch what each stage emits. The fastest way to settle whether sorted comes before or after limit.
javap -p Order.classSee the members a record or inner class really has: the generated accessors and equals, the synthetic this$0 and val$base fields, and that every List<T> is a plain List.
javap -cFind the checkcast the compiler inserted at every generic read, and the invokedynamic a lambda compiles to.
javac -Xlint:all -WerrorTurn raw types, unchecked casts and missing @Override into build failures. -Xlint:rawtypes alone catches the List that should have been List<?>.
java -Dfile.encoding=…Reproduce a charset bug by running with the platform default a customer's machine has. Since Java 18 the default is UTF-8 unless you set this.
