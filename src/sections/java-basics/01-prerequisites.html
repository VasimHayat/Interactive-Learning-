What you need installed

A JDK 21 or newer, and nothing else. No IDE is required — every example in this module compiles from the command line.

java -version    # expect: openjdk version "21.x" or newer
javac -version   # the compiler ships with the JDK, not the JRE

If javac is missing but java works, you have a JRE rather than a JDK. Section 1 explains the difference and why it matters.

If you are coming from a specific language
  • Python or JavaScript: the biggest adjustment is static typing and the primitive/object split (sections 2 and 3). Expect the compiler to reject things your old language happily ran.
  • C or C++: there are no pointers you can dereference, no destructors, and no manual free. But there are references, and the distinction between a reference and the object it points to matters constantly.
  • C#: the languages rhyme, but Java's generics are erased rather than reified (section 13), and == on objects never means value equality (section 10).
