Glossary

Thirty terms, each linked back to the section that introduces it. The same entries drive the flashcard deck below — one list, two ways to use it.

Flashcards

Autoboxing
Automatic conversion between a primitive and its wrapper class, inserted by the compiler. Convenient, but the source of null-unboxing crashes and == surprises. §2
Bytecode
The portable instruction set javac emits into .class files. Not machine code — it targets the abstract JVM, which is why one build runs everywhere. §1
Checked exception
An Exception that is not a RuntimeException. The compiler forces you to catch it or declare it. Models conditions a correct program can still meet. §11
Class loader
The JVM component that finds a .class file, links it, and makes the type available. Runs on first active use, not at startup. §1
ConcurrentModificationException
Thrown when a collection is structurally changed while being iterated. Despite the name, usually a single thread doing it to itself. §5
Defensive copy
Returning a copy of internal mutable state rather than the field itself, so callers cannot reach past your invariants. §14
Dynamic dispatch
Choosing which overridden method body runs from the object's runtime class, not the declared type of the variable. §8
Encapsulation
Keeping state private and exposing operations that enforce the rules, so an object cannot be put into an invalid condition from outside. §8
Enhanced for loop
for (T x : items). Uses an iterator underneath, and cannot go out of bounds because you never write a bound. §5
Erasure
Generic type arguments exist only at compile time and are removed from the bytecode. Why new T(), new T[] and instanceof List<String> are all impossible. §13
equals/hashCode contract
Objects that are equals must return the same hashCode. Break it and every hash-based collection gives wrong answers silently. §10
final
Prevents reassignment of a variable, overriding of a method, or subclassing of a class. It does not make the referenced object immutable. §14
Immutability
An object's state cannot change after construction. String is the canonical example; every "modifying" method returns a new instance. §3
Instance initializer
A bare { … } block in a class body. Runs on every construction, after the implicit super() and before the constructor body. §9
Integer cache
Integer.valueOf returns shared instances for −128…127. Why == on boxed values is true for small numbers and false for large ones. §2
Interface
A contract with no instance state. A class may implement many, which is why it is the default choice for expressing a capability. §8
JIT compiler
Compiles frequently executed bytecode to native code while the program runs. Why JVM benchmarks need a warm-up phase. §1
JDK / JRE / JVM
Development kit (adds javac and tools) ⊃ runtime environment (JVM plus class library) ⊃ the virtual machine that executes bytecode. §1
Overloading
Several methods with one name and different parameter types. Resolved by the compiler in three phases: exact/widening, then boxing, then varargs. §7
Overriding
A subclass replacing an inherited method with the same signature. Resolved by the JVM at runtime. Always mark it @Override. §8
Package-private
The access level you get by writing no modifier at all: visible to every class in the same package, and nothing else. §14
Pass-by-value
Java's only calling convention. For references the reference is copied, so a method can mutate your object but cannot repoint your variable. §7
Polymorphism
Writing code against a supertype and having it work for every subtype, with the actual behaviour selected at runtime. §8
Primitive
One of the eight non-object value types. Cannot be null, cannot go directly into a collection, and has a fixed bit width. §2
Raw type
A generic type used without its type argument, e.g. plain List. Legal for backward compatibility; switches off the compiler's help. §13
Short-circuit evaluation
&& and || skip the right operand when the left already decides the result. Load-bearing for null and divide-by-zero guards. §4
static
Belongs to the class rather than any instance. One copy shared by everything, initialised once on first active use. §9
String pool
A JVM-managed set of shared String instances holding compile-time literals and interned strings. Why == sometimes appears to work. §3
Try-with-resources
try (R r = …). Closes what it acquired, in reverse order, and suppresses rather than discards a secondary exception from close(). §11
Unchecked exception
A RuntimeException subclass. Needs no declaration, and models a programming error whose fix is to change the code. §11
