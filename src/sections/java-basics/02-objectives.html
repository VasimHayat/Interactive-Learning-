The contract

Learning objectives

By the end of this module you will be able to do each of the following without reaching for a reference. The final quiz tests exactly these.

  1. Trace a .java file through javac, class loading, and JIT compilation, and say which artefact the JDK, JRE and JVM each own.
  2. Predict the result of integer arithmetic that overflows, of == on boxed values, and of division and modulo on negative operands.
  3. Explain why String is immutable, when two string literals share one object, and what intern() changes.
  4. Choose the right collection for a stated access pattern, and justify it in terms of the cost of the operations you actually perform.
  5. Implement equals and hashCode as a matched pair, and diagnose the failure that follows from overriding only one.
  6. Distinguish checked from unchecked exceptions, and write a try-with-resources block that closes its resources in the correct order.
  7. Resolve an overloaded method call by hand, in the same three phases the compiler uses.
  8. Diagnose a NullPointerException, a ClassCastException from a raw type, and a ConcurrentModificationException from their stack traces and fix each at its cause.
  9. Apply the four access levels correctly, and state which one a member gets when you write no modifier at all.
Deliberately out of scope

Lambdas, streams, concurrency, records, sealed types, pattern matching, the module system and reflection all belong to Java Intermediate. They are mentioned here only where a beginner would otherwise be confused by seeing them in real code. Generics appear, but only as far as declaring and consuming List<Product> — wildcards and erasure edge cases are the advanced module's job.
