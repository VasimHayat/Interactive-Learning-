Further reading

Primary sources only — specifications, official documentation, and the two books that are actually worth the shelf space. These are links, but nothing on this page loads them; the module remains fully offline.

Specifications and official docs

  • The Java Language Specification, Java SE 21 Edition — the final word on every rule in this module. Chapter 5 (conversions and promotions) and §15.12 (method invocation) are where the overload-resolution phases are defined.
    https://docs.oracle.com/javase/specs/jls/se21/html/index.html
  • The Java Virtual Machine Specification, Java SE 21 Edition — class loading, linking, initialization order, and the bytecode instruction set.
    https://docs.oracle.com/javase/specs/jvms/se21/html/index.html
  • Java SE 21 API documentation — the Javadoc. Read the class-level notes on HashMap, ArrayList and String; they document the performance characteristics this module summarises.
    https://docs.oracle.com/en/java/javase/21/docs/api/index.html
  • Object.equals and Object.hashCode Javadoc — the contract itself, stated in about two hundred words. Worth reading in the original.
    https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/lang/Object.html
  • The Java Tutorials — Oracle's introductory trail. Uneven, occasionally dated, but the Collections and Generics trails are solid.
    https://docs.oracle.com/javase/tutorial/

Books

  • Effective Java, Joshua Bloch, 3rd edition — the single most useful Java book. Items 10 through 14 cover equals, hashCode, toString, Comparable and clone in far more depth than section 10 here. Read it after this module, not before.
  • Java: A Beginner's Guide, Herbert Schildt — a conventional ground-up introduction if you want a second explanation of the same fundamentals in a different voice.
  • Java Concurrency in Practice, Brian Goetz et al. — the standard reference for the threading material in Java Advanced. Predates virtual threads but the model it teaches is unchanged.

Tools worth knowing early

Useful JDK tools and what they are for
ToolUse it to
jshellTry a snippet without writing a class or a main. The fastest way to settle an argument about what Java does.
javap -cDisassemble a .class file. Shows you the string concatenation the compiler generated, and that generics really are erased.
javac -Xlint:all -WerrorTurn every warning into a build failure. Catches raw types and unchecked casts before they reach production.
jcmd / jstackInspect a running JVM — thread dumps, heap info, GC statistics.
Next module

The course continues in two further modules, both built on the same warehouse example.

Java Intermediate picks up exactly where this stops: generics in depth (wildcards, PECS, bounded types), nested and inner classes, interfaces and enums in full, lambdas and method references, streams and collectors, Optional, records, sealed types with pattern matching and switch expressions, Comparator and immutability, the internals of HashMap and ArrayList, java.time, and file I/O.

Java Advanced then covers the runtime: threads and the Java memory model, locks and concurrent collections, executors, CompletableFuture and virtual threads, garbage collection and JVM tuning, class loading, reflection and annotations, the module system, and performance measurement.
