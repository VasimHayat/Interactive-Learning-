Exceptions

Common exceptions, their cause and the usual fix
ExceptionChecked?Usual cause and fix
NullPointerExceptionnoUsing a reference that was never assigned, or an unboxed null from a map. Read the Java 14+ message — it names the expression.
ArrayIndexOutOfBoundsExceptionno<= where < was meant. Prefer the enhanced for.
ClassCastExceptionnoA raw type let the wrong element in. Parameterise and treat unchecked warnings as errors.
NumberFormatExceptionnoInteger.parseInt on non-numeric input. Validate, or catch at the boundary.
IllegalArgumentExceptionnoA caller violated a documented precondition. Throw it yourself from constructors.
IllegalStateExceptionnoValid operation, wrong time — shipping an already-shipped order.
ConcurrentModificationExceptionnoStructural change while iterating. Use removeIf or Iterator.remove.
UnsupportedOperationExceptionnoMutating an immutable view (List.of, Arrays.asList).
IOExceptionyesThe environment failed. Handle or declare; never swallow.
StackOverflowErrorno (Error)Runaway recursion — usually a missing base case. Do not catch.

Command line

javac -encoding UTF-8 -d out src/*.java   # compile into out/
java -cp out com.acme.Main arg1           # run: class NAME, not file name
java Main.java                            # single-file source mode, no javac needed
jar --create --file app.jar -C out .      # package
java -jar app.jar                         # run a jar (needs Main-Class in the manifest)
javac -Xlint:all -Werror src/*.java       # make every warning fatal
jshell                                    # REPL for trying snippets

Rules that prevent most beginner bugs

  1. Compare objects with equals, never ==.
  2. Override equals and hashCode together, from the same fields.
  3. Write @Override every time you intend to override.
  4. Declare fields private; return copies of mutable internal state.
  5. Prefer the enhanced for; you cannot go out of bounds without a bound.
  6. Never concatenate strings in a loop — use StringBuilder.
  7. Never use double for money — use BigDecimal or integer cents.
  8. Never leave a catch block empty.
  9. Use try-with-resources for anything closeable.
  10. Parameterise your generics; treat unchecked warnings as errors.
  11. Declare the interface, construct the implementation.
  12. Prefer getOrDefault to get when a miss means zero.
