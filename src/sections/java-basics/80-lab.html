Hands-on lab: build the InventoryService

Six steps, each exercising something from the sections above. Write each one before opening the solution — reading a solution you have not attempted teaches almost nothing. Work in a single directory; every step compiles on its own with javac *.java.

Starter
mkdir inventory-lab && cd inventory-lab
# create Part.java, InventoryService.java and Lab.java as you go
javac *.java && java Lab

Everything is in the default package to keep the lab to three files. Real code would use package com.acme.inventory; and matching directories.

Step 1 — an encapsulated value type §8, §14

Write Part with a String sku and an int priceInCents. Both private final. The constructor must reject a null or blank SKU and a negative price with IllegalArgumentException. Expose read accessors, no setters.

Solution — step 1
public final class Part {
    private final String sku;
    private final int priceInCents;

    public Part(String sku, int priceInCents) {
        if (sku == null || sku.isBlank())
            throw new IllegalArgumentException("sku must not be blank");
        if (priceInCents < 0)
            throw new IllegalArgumentException("price must not be negative: " + priceInCents);
        this.sku = sku;
        this.priceInCents = priceInCents;
    }

    public String sku() { return sku; }
    public int priceInCents() { return priceInCents; }
}

Validating in the constructor means a Part can never exist in an invalid state — far stronger than checking at every use site. final on the class blocks the subclass that would break equals symmetry in step 2.

Step 2 — the equality contract §10

Two Parts are the same part when their SKUs match; price is not part of identity. Implement equals, hashCode and toString accordingly.

Solution — step 2
@Override public boolean equals(Object o) {
    if (this == o) return true;
    if (!(o instanceof Part other)) return false;
    return sku.equals(other.sku);
}

@Override public int hashCode() { return sku.hashCode(); }

@Override public String toString() {
    return "Part[" + sku + ", " + priceInCents + "c]";
}

Hash on exactly the field equals uses, and no other. Because sku is final, the hash can never drift after the part is used as a map key.

Step 3 — pick the right collections §12

InventoryService needs stock levels keyed by SKU, and a record of which SKUs have been picked this run, in the order picked. Choose both types and justify the choice to yourself before revealing.

Solution — step 3
private final Map<String, Integer> onHand = new HashMap<>();
private final Set<String> pickedThisRun = new LinkedHashSet<>();

HashMap for O(1) keyed lookup where iteration order is irrelevant. LinkedHashSet because the picks must be unique and reportable in order — a HashSet would lose the order and a List would allow the same SKU twice.

Step 4 — a domain exception §11

Add reserve(String sku, int qty). Throw IllegalArgumentException for a non-positive quantity, and a custom OutOfStockException when the request exceeds stock. Decide whether it should be checked or unchecked, and be able to defend it.

Solution — step 4
public class OutOfStockException extends Exception {   // CHECKED
    private final String sku;
    public OutOfStockException(String sku, int requested, int available) {
        super("cannot reserve " + requested + " of " + sku + "; only " + available + " on hand");
        this.sku = sku;
    }
    public String sku() { return sku; }
}

public void reserve(String sku, int qty) throws OutOfStockException {
    if (qty <= 0) throw new IllegalArgumentException("qty must be positive: " + qty);
    int available = onHand.getOrDefault(sku, 0);
    if (qty > available) throw new OutOfStockException(sku, qty, available);
    onHand.put(sku, available - qty);
    pickedThisRun.add(sku);
}

Checked, because running out of stock is a normal business outcome the caller must decide about — back-order, substitute, or refuse — not a programming mistake. The bad quantity is unchecked, because that is a caller bug. Note getOrDefault rather than get: an unknown SKU is zero stock, and get would return null and throw on unboxing.

Step 5 — try-with-resources §11

Add loadFrom(Path) that reads lines of SKU,QTY and populates onHand, using try-with-resources so the reader always closes. Skip blank lines and lines starting with #.

Solution — step 5
public void loadFrom(Path file) throws IOException {
    try (BufferedReader in = Files.newBufferedReader(file)) {
        String line;
        while ((line = in.readLine()) != null) {
            line = line.strip();
            if (line.isEmpty() || line.startsWith("#")) continue;
            String[] parts = line.split(",");
            if (parts.length != 2)
                throw new IOException("malformed line: " + line);
            onHand.put(parts[0].strip(), Integer.parseInt(parts[1].strip()));
        }
    }
}

The reader closes whether the loop finishes, throws, or returns early. strip() rather than trim() so a non-breaking space in an exported file does not survive into a SKU. IOException is declared, not swallowed — the caller decides what a corrupt file means.

Step 6 — make it generic §13

Extract a Repository<T> interface with save(T), findById(String) and count(), then have a PartRepository implement Repository<Part>.

Solution — step 6
public interface Repository<T> {
    void save(T item);
    T findById(String id);
    int count();
}

public class PartRepository implements Repository<Part> {
    private final Map<String, Part> byS_ku = new HashMap<>();
    @Override public void save(Part item) { byS_ku.put(item.sku(), item); }
    @Override public Part findById(String id) { return byS_ku.get(id); }
    @Override public int count() { return byS_ku.size(); }
}

Callers get Part back with no cast and no possibility of a ClassCastException. findById returning null for a miss is the conventional shape here; Optional<Part> is the modern alternative and is covered in Java Intermediate.

The finished thing

All six steps assembled. This program is compiled and executed during the build of this page, so the output below is what it really prints.

import java.util.HashMap;
import java.util.LinkedHashSet;
import java.util.Map;
import java.util.Set;

public class Lab {

    static final class Part {
        private final String sku;
        private final int priceInCents;

        Part(String sku, int priceInCents) {
            if (sku == null || sku.isBlank())
                throw new IllegalArgumentException("sku must not be blank");
            if (priceInCents < 0)
                throw new IllegalArgumentException("price must not be negative: " + priceInCents);
            this.sku = sku;
            this.priceInCents = priceInCents;
        }

        String sku() { return sku; }
        int priceInCents() { return priceInCents; }

        @Override public boolean equals(Object o) {
            if (this == o) return true;
            if (!(o instanceof Part other)) return false;
            return sku.equals(other.sku);
        }
        @Override public int hashCode() { return sku.hashCode(); }
        @Override public String toString() { return "Part[" + sku + ", " + priceInCents + "c]"; }
    }

    static class OutOfStockException extends Exception {
        OutOfStockException(String sku, int requested, int available) {
            super("cannot reserve " + requested + " of " + sku + "; only " + available + " on hand");
        }
    }

    interface Repository {
        void save(T item);
        T findById(String id);
        int count();
    }

    static final class PartRepository implements Repository {
        private final Map bySku = new HashMap<>();
        @Override public void save(Part item) { bySku.put(item.sku(), item); }
        @Override public Part findById(String id) { return bySku.get(id); }
        @Override public int count() { return bySku.size(); }
    }

    static final class InventoryService {
        private final Map onHand = new HashMap<>();
        private final Set pickedThisRun = new LinkedHashSet<>();

        void stock(String sku, int qty) { onHand.put(sku, onHand.getOrDefault(sku, 0) + qty); }

        void reserve(String sku, int qty) throws OutOfStockException {
            if (qty <= 0) throw new IllegalArgumentException("qty must be positive: " + qty);
            int available = onHand.getOrDefault(sku, 0);
            if (qty > available) throw new OutOfStockException(sku, qty, available);
            onHand.put(sku, available - qty);
            pickedThisRun.add(sku);
        }

        int onHand(String sku) { return onHand.getOrDefault(sku, 0); }
        Set picked() { return Set.copyOf(pickedThisRun); }
        String pickedInOrder() { return String.join(", ", pickedThisRun); }
    }

    public static void main(String[] args) {
        PartRepository repo = new PartRepository();
        repo.save(new Part("BOLT-7", 80));
        repo.save(new Part("NUT-3", 25));
        repo.save(new Part("BOLT-7", 90));          // same sku: replaces, does not duplicate
        System.out.println("repo count      = " + repo.count());
        System.out.println("lookup          = " + repo.findById("BOLT-7"));
        System.out.println("equal by sku    = " + new Part("BOLT-7", 1).equals(new Part("BOLT-7", 999)));

        InventoryService inv = new InventoryService();
        inv.stock("BOLT-7", 10);
        inv.stock("NUT-3", 4);

        try {
            inv.reserve("BOLT-7", 3);
            inv.reserve("NUT-3", 4);
            inv.reserve("BOLT-7", 2);
            inv.reserve("NUT-3", 1);                 // NUT-3 is exhausted
        } catch (OutOfStockException e) {
            System.out.println("caught          = " + e.getMessage());
        }

        try {
            inv.reserve("BOLT-7", 0);
        } catch (IllegalArgumentException e) {
            System.out.println("bad qty         = " + e.getMessage());
        } catch (OutOfStockException e) {
            System.out.println("unreachable");
        }

        System.out.println("BOLT-7 on hand  = " + inv.onHand("BOLT-7"));
        System.out.println("picked in order = " + inv.pickedInOrder());
        System.out.println("unknown sku     = " + inv.onHand("NOPE"));
    }
}

Extensions worth attempting
  • Add release(sku, qty) that returns stock and removes the SKU from pickedThisRun only when nothing of it remains reserved. You will need a second map — think about what breaks if you forget it.
  • Make reserve atomic across several SKUs: either all succeed or none do. What has to happen to pickedThisRun on rollback?
  • Give Part a Category enum and group the repository by it. Which Map type gives you categories in declaration order?
