How to use this module

Work through it at your own pace. Your section checkmarks, quiz answers, flashcard marks and notes are saved in this browser under a key scoped to this file, so closing the tab loses nothing and no other module can overwrite it. Nothing is sent anywhere — this page makes no network requests at all. Press ? at any time for the keyboard shortcuts, and use Reset progress in the sidebar to start over.

Every code sample in this module was compiled and executed against a real JDK 21 as part of the build. If an Expected output block appears under a program, that text is what the program actually printed, not what it ought to print. Where a widget animates execution rather than reporting it, it is labelled Simulated — Java cannot run in a browser, and this module does not pretend otherwise.

One running example

Rather than Foo and bar, everything here is built around a small warehouse system: a Product has a SKU and a price, an Order holds OrderLines, and an InventoryService tracks stock. The same types reappear from the first example to the final lab, so you spend your attention on the language rather than on re-reading the setup.
